which one?

sdd_02 · fig.01
6 triggers

the card

sdd_03 · microsd
format
fat32, mbr partition · 32 gb sdhc recommended · sd association formatter
speed
misc › tests › test sd speed · ~3 mb/s max · under 1.8: suspect · samsung evo runs high speed, sandisk extreme doesn’t
supplied card
fine for firmware and wavetables · not guaranteed for streaming wavs

05

file names

sdd_05 · suffixes
_C3 · _F#2
natural pitch · sharps only, no flats
_SW40
switch point (midi note) in multisample
_V1 · _V2
velocity layers · lowest number = softest
_RR1 · _RR2
round robins · [ round robin mode ]: in order · random · random2 (no repeats) · random3 (shuffled sets)
both
velocity first: snare_V2_RR1.wav
no note name
multisample numbers them from note 48 (C3) up · one file per semitone
06

sd 6 triggers

sdd_06 · algorithm 4
in 1 … in 6
trigger voice 1 – 6 · gate voltage = velocity, 5 V = max
[ sample 1-6 ]
file per voice · −1 = voice off · [ r ] on it previews
[ folder ] [ folder 2-6 ]
one shared folder, or −1 = use the shared one, per voice
[ output 1-6 ]
1 – 4 mono · 5 = 1/2 stereo · 6 = 3/4 · 7 / 8 = 1/2 + out 3 / out 4
[ gain ] [ pan ]
−6 db default · pan on stereo outs
[ env time ]
100 = play to the end (default) · lower = shorter tails
[ choke group ]
1 – 3 · a hit cuts the others in its group (closed hat › open hat)
[ start offset ]
start later in the file, in 0.1 % steps
[ transpose ] [ fine ]
per voice tuning
07

sd multisample as drums

sdd_07 · algorithm 3 · cv
[ input mode ]
3 cv/gate pairs · gates in 4 in 3 in 6 = timbre 1 · 2 · 3
pitch
in 2 in 1 in 5 pair with those gates
[ folder ] [ folder 2 ] [ folder 3 ]
one drum folder per timbre · −1 = share folder 1
[ release ]
127 = play the file to its end · short triggers otherwise fade it early
[ attack ]
0 for a sharp hit
[ output mode ]
per gate 1-2-3: timbres to outs 1, 2, 3 mono · out 4 = paraphonic gate
[ gain ]
default is set for chords · raise it for single hits
[ max voices ]
8 shared by all three timbres
08

picking the sample

sdd_08 · multisample pitch cv
one file
an empty pitch input sits at 0 V · use [ transpose ] if the hit sounds pitched
many files
1 V/oct · each 1/12 V steps to the next file in the folder
[ gate offset ]
delays the gate so a moving cv lands first (0 – 496)

sdd_09
