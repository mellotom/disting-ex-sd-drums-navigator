what this sector is

sdd_01 · fig.01
the job
disting ex plays drum samples off the card · stolperbeats sequences them
the algorithm
[ 04 ] sd 6 triggers · six voices, each its own trigger, sample, output · [ p ] › algorithms › choose single › 4
two routes
six trigger cables into the inputs, or midi through a tiny midi breakout · or both
the screen
the voice’s file · playing: velocity, layer, round robin (› = neither) · [ r ] on [ sample ] auditions

02

a voice

sdd_02 · six of everything
in 1 … in 6
trigger voice 1 – 6 · gate voltage = velocity, 5 V = max
[ sample 1-6 ]
the file (0 – 999 in the folder) · −1 switches the voice off
[ folder 2-6 ]
a folder of its own, or −1 = the shared [ folder ]
[ gain 1-6 ]
−40 to +6 db · −6 db default, so six hits can stack
[ env time 1-6 ]
100 = play the file to its end (default) · lower = shorter tails
[ transpose ] [ fine ]
±60 semitones, ±100 cents per voice · tune toms, pitch a kick
[ start offset ]
skip into the file in 0.1 % steps · the ms shows on screen
[ round robin ]
mode: in order · random · random2 (no repeats) · random3 (shuffled sets)

03

the card

sdd_03 · microsd
format
fat32, mbr partition · 32 gb sdhc recommended · sd association formatter
speed
misc › tests › test sd speed · ~3 mb/s max · under 1.8: suspect · samsung evo runs high speed, sandisk extreme doesn’t
supplied card
fine for firmware and wavetables · not guaranteed for streaming wavs
04

folders

sdd_04 · fig.02
where
folders of .wav files (24 bit ok) at the top level of the card, not nested
order
sorted alphabetically · [ folder ] (0 – 999) counts down that list, files too
tip
number the names (00 kit 808, 01 kit 909 …) so folder numbers stay put
kits
one folder per kit, or one folder per drum and [ folder 2-6 ] to mix kits
switching
a new folder loads after you press the menu button to confirm
playlist.txt
optional · picks files, order and per-file settings · files are one-shot unless set to loop

07

chokes · feel

sdd_07 · fig.05
[ choke group ]
per voice · 0 off · 1 – 3 · a hit stops the other voices in its group
hats
hihat 1 and 2 in group 1: closed cuts open
rolls
stolperbeats feeling: hihat 2 becomes a burst · choked, each hit cuts the last
flam · slop
kick, snare (and hats) land a touch late · long tails smear
[ linear ]
stolperbeats thins out stacked hits · one voice at a time, like a choke on the whole kit

cv · knob mappings

sdd_13 · mappings menu

any input offsets any of the first 64 parameters · bi / unipolar, %/V · gate type: over 1 V = min ↔ max

11

tiny midi breakout

sdd_11 · fig.06
to the ex
2 hp, passive, six trs sockets · ribbon to the rear GT4/MIDI header, pin 1 nearest the GT4 text
midi in
header pins 3 + 4 to a socket wired type a (tip, ring)
midi out
pins 1 + 2 to another socket (ring, tip) · soft thru forwards midi in › out · type b = swap tip, ring
the cable
stolperbeats midi out (trs a) › that socket · activity shows top right of the display

12

midi in

sdd_12 · notes 48 – 53
notes
six neighbouring notes fire voices 1 – 6 · 48 – 53 by default (menu) · channel: settings › midi/i2c › rx channel (single)
stolperbeats
midi edit: every track on that channel · kick 48, snare 49, hh1 50, hh2 51, p1 52, p2 53 · hold [ ◄ ] saves the bank
velocity
per track (1 LED = 8 steps) · picks the _V layer, unlike 10 V cable triggers
subdiv
its notes go out too · park it on another channel
free the inputs
turn trigger inputs off in the algorithm menu · then use them as cv
stop
all notes off · all sound off: menu, or cc 123 / 120

sdd_14 · cables + midi + cv

hands on
l › [ env time 4 ] (open hat length) · r › [ start offset 2 ] (snare bite)
