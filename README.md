# disting-ex-sd-drums-navigator

travelers guide for drumming in parallel worlds: a disting ex sector page for playing drum samples off the microsd card with **03 sd multisample** and **04 sd 6 triggers**, sequenced by a stolperbeats. card format and speed, folder organisation, file naming (velocity layers, round robins, switch points), trigger and choke settings, picking samples by cv, and midi through an expert sleepers tiny midi breakout.

source: the disting ex user manual (firmware 1.26) and the tiny midi breakout page.

not affiliated with expert sleepers or making sound machines.
